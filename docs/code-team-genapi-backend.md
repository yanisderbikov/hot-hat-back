# SCRUM-30 — закрытый тест «Кода команды» на Java-бэкенде

Этот пилот **не подключён** к настоящим матчам, командным карточкам,
накопительной аналитике и потокам LiveKit. Адрес нужен для проверки одной
модели GenAPI на заранее согласованных игровых эпизодах.

## Настройка секретов

Переменные ставятся **только на сервер Java-бэкенда**, в том окружении,
где развёрнута ветка `new-dev`:

- `GENAPI_API_KEY`: ключ GenAPI. Никогда не помещать во фронтенд или репозиторий.
- `CODE_TEAM_PILOT_ENABLED` (необязательно): по умолчанию `true`. Установить `false`, чтобы запретить платные запросы в пилоте. Значение берётся из `application.properties` через `${CODE_TEAM_PILOT_ENABLED:true}`.
- `CODE_TEAM_MODEL=gemini-3-8-flash` (по умолчанию): модель GenAPI.

Ни ключ, ни включённый по умолчанию флаг сами не расходуют баланс. Платный вызов
возможен только у `OWNER` при запросе `live: true` и указанном согласии обоих
участников. При необходимости временно остановить расходы, установить
`CODE_TEAM_PILOT_ENABLED=false` в Railway. Сервер ограничивает платные запросы
одним в минуту на процесс. Для регулярного продукта потребуются лимиты в БД,
очереди и бюджеты.

## Endpoint

`POST /api/v2/admin/code-team/pilot`: только роль `OWNER`. Требуется
пользовательская авторизация Hot Hat. До реального подключения к игре
нельзя выдавать его обычным игрокам.

Вариант без расходов (`live: false`):

```json
{
  "teamClass": "friends",
  "players": [
    {"id": "p1", "nickname": "Маша", "consented": true},
    {"id": "p2", "nickname": "Саша", "consented": true}
  ],
  "evidence": [
    {"id": "e1", "playerId": "p1", "type": "hint", "text": "Подсказка в два слова", "source": "human", "synthetic": false},
    {"id": "e2", "playerId": "p2", "type": "guess", "text": "Угадал с первого раза", "source": "human", "synthetic": false},
    {"id": "e3", "playerId": "p1", "type": "speech", "text": "Подменённая речь", "source": "human", "synthetic": true}
  ],
  "live": false
}
```

Возвращает `mode: dry-run`, модель, число реальных эпизодов и окончательный
промпт. Подмены, боты и синтетические эпизоды из промпта исключаются.

Для **одного платного запроса** нужен активный флаг `code-team.pilot.enabled`
(по умолчанию `true`) и явный запрос `live: true`, всё остальное то же самое. Ответ будет иметь
`mode: live` и `analysis`. Провайдер может списать деньги и при сетевом
таймауте; автоматических повторов нет. Модель ограничена 750 выходными
токенами; размер входа ограничен 30 эпизодами по 200 символов.

## Что пока не реализовано

- Достоверное серверное подтверждение согласия и состава команды.
- Получение записей двух участников по окончании конкретной игры.
- Расшифровка речи (GenAPI STT), хранение истории, общий отчёт для гостей.
- Различающиеся долговременные показатели для пар, друзей и коллег.
- UI отчёта игрокам, лимиты расходов на сутки/месяц в БД.

До реализации этих пунктов нельзя считать механизм готовым на сайте.
