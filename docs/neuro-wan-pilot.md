# SCRUM-59 — Обратимый пробный режим Wan 3.0 720p

Дата: 21.11.2026. Это **интеграция без платного end-to-end испытания**, пока нет нового явно подтверждённого заказа владельца.

## Что переключено

- **Только новые** задания `/neuro-replacement/` (простой 20–30-секундный загруженный видеообразец) и новые задания игрового теста с динамическим сценарием выбирают `wan-3`, разрешение `720p`.
- `GENAPI_API_KEY` остаётся прежним. Отдельный WAN API-ключ не нужен.
- Старые job с GenAPI task ID `kling-video-o3` продолжают использовать Kling при GET/истории/recovery и не переписываются.
- Сохраняем модель на уровне каждой новой job: `provider_requests["__diag.videoModel"]`. В owner status открыто поле `videoModel`.
- Для Wan отправляем HTTPS `video_urls` (8-секундный identity reference), `image_url` (реальный первый кадр), `duration`, `resolution="720p"`, `aspect_ratio="16:9"`, `audio=false`, `enable_prompt_expansion=false` и сцену. `elements`, `pro`, `generate_audio` от Kling НЕ отправляются.
- Сохраняем внешнюю озвучку Gemini TTS → Chatterbox → Lip Sync и обработку Longpipe после получения итогового файла. Никаких гарантий качества жестов и сходства без реального MP4.
- Проверяем URL/media и дикцию до дорогого видео. Отправляем **не больше одного платного POST на этап**, сохраняем ID перед проверкой результата, существующий оплаченный ID повторно не создаётся.
- Предварительная цена (без гарантии максимума) выводится до явного согласия: Wan 25 ₽/сек + оценка голосовых этапов.

## Откат

Для **новых** заданий установить `NEURO_NEW_VIDEO_MODEL=kling-video-o3` в переменных backend Railway. Для возврата к Wan — `NEURO_NEW_VIDEO_MODEL=wan-3`. Старые job всегда читаются по собственной сохранённой модели, независимо от флага. Неверное значение означает отказ без новой оплаты.

## Предварительная проверка и ограничения

- Wan reference payload использует публичную схему https://gen-api.ru/model/wan-3/api.
- Цена 720p — 25 ₽/сек https://gen-api.ru/model/wan-3.
- Настройка не выполняет GenAPI POST и не требует пополнения. Пользователь самостоятельно проверяет баланс на https://gen-api.ru/.
- Полноценный тест на новом оплачиваемом 10-секундном ролике нужно провести после пополнения и подтверждения в интерфейсе. Отдельно проверить выполнение жестов, сходство, точные русские реплики, губы, тембр и прозрачный WebM. Если GenAPI отклонит новую комбинацию reference inputs, ошибка сохраняется без скрытого перехода на платный Kling.
